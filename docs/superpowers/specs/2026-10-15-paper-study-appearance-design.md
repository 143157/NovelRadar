# 小说雷达：B「纸页书房」整体外观设计

日期：2026-10-15（Asia/Shanghai）

状态：用户已确认风格与五页范围；本说明待用户复核，尚未进入实施。

基线：应用修复提交 b15b995，交付记录提交 d4b4c18。

## 已确认的目标

用户在三种本地视觉对比稿中选择 B「纸页书房」，并同意先统一书架、搜书、书籍详情、下载、书源五个页面。整体使用纸色背景、灰绿点缀、书卷感标题和两列大封面，保留用户选定的紫色 App 图标。

这次是现有原生 Android/Compose 应用的外观改版，不是建立新网站或新书城。目标是让五页像同一套产品，同时保持全部真实状态、操作入口和安全提示。阅读正文、背景设置、字数进度、段落缩进、翻页与滚动行为不改。

## 方向选择与独特性

已比较：

- A「紫墨轻简」：呼应紫色图标、轻卡片、三列紧凑书架。
- B「纸页书房」：纸色、灰绿、书卷感标题、两列大封面；用户选定。
- C「深夜藏书」：墨蓝、淡紫、信息密集列表。

B 的视觉重点是书本而非装饰：纸页分隔的「继续阅读」区，左侧书名和真实进度、右侧小封面；下方两列大封面。灰绿用于动作和选中状态，不加入赤陶色主色、背景纹理、仿纸噪点、渐变横幅或装饰性数字。保留原图标而不是重画品牌。

浏览器稿只说明方向，不是像素级合同：演示书名、简介、封面、进度和书源数量不得进入生产界面。原生页面只使用已有业务数据。

## 视觉规则

### 配色

| 角色 | 颜色 | 用途 |
| --- | --- | --- |
| 纸色底 | #F5F0E7 | 五页背景 |
| 纸面 | #FBF8F1 | 卡片、表单与底部导航底 |
| 墨色 | #373A36 | 标题、正文、主要信息 |
| 辅助灰绿 | #696F65 | 作者、来源、说明、次级信息 |
| 主灰绿 | #566457 | 主按钮、选中导航、焦点、进度 |
| 细线 | #DCDCCF | 非交互分隔线和装饰性边界 |

状态色独立于主色：警告 #8A4F2B、错误/删除 #A33B32；成功可以使用主灰绿，但必须同时显示准确状态文字。输入框可见边界使用辅助灰绿，焦点使用主灰绿，不能仅用浅细线表达可操作边界。主按钮使用主灰绿底与纸面色文字。

预览辅助色 #7D8177 在纸色底上的实算对比度约 3.50，因此原生方案改为 #696F65，约 4.55；不透明墨色约 10.16，主灰绿约 5.51，纸面色/主灰绿按钮约 5.90。禁止额外透明度削弱启用状态的小字。正常文字采用至少 4.5:1 的验收门槛，参照 [W3C Contrast Minimum](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)；禁用控件和纯装饰线单独审查。

这是固定浅色的非阅读页主题，不新增自动深色模式或跟随壁纸配色。阅读器已有 DAY/PAPER/NIGHT 选择保持原样。

### 字体与尺寸

- 页面标题：系统衬线体优先，28sp，常规或中等字重；避免极粗黑体大标题。
- 分区标题：系统衬线体优先，20sp；书架书名 17sp、最多两行，超长省略但详情页保留完整标题。
- 说明与交互：系统无衬线体，主要文字 14–16sp，辅助信息不小于 12sp。
- 进度数字可使用现有等宽字体；不再让下载数字压过书名和操作。
- 「书卷感」不等于保证每台手机都有 Windows 宋体：采用 Android 系统 FontFamily.Serif 和系统中文回退，本轮不下载字体、不增加字体依赖或字体资源包。

### 布局、组件与图标

- 间距采用 4/8/12/16/20/24/32dp；页面常规横向留白 20dp，列表项和相关信息保持一致。
- 书架两列，间距约 18dp；封面沿用现有约 0.72 宽高比。窄屏和大字允许卡片自然长高，不把辅助信息挤成不可见。
- 长列表继续使用 Lazy 容器；横屏/宽屏主内容居中、最大宽度约 600dp，不新增第三列或另一套平板信息架构。
- 封面小圆角 2dp；普通纸面组件 4–8dp，细边或分隔线；移除当前粗黑 2dp 卡片框与大块橙色/黑色页头。
- 按钮及设置行保留至少 48dp 的交互区域；不以视觉尺寸缩小触控区域，依据 [Android Compose accessibility defaults](https://developer.android.com/develop/ui/compose/accessibility/api-defaults)。
- 底部导航仍为「书架、搜书、下载、书源」，顺序和路由不变。文本字符图标改为统一描边的本地矢量图标，不引入网络图标资源或新图标依赖。
- 独立图标操作有中文无障碍标签；已有文字的导航避免重复朗读，保留选中、禁用、开关和长按语义。
- 不新增过场动画、重排动画、刷新动效或仿真翻页。保留现有必要的加载与进度指示。

## 五页落地范围

### 书架

保留「我的书架」、刷新、空态与去搜书入口。将现有黑色继续阅读卡变为纸页式区域，显示已有真实阅读位置；两列封面网格保留未读章节提示、最新章节、阅读位置和详情入口。长按移出书架及「同时删除本地章节」确认逻辑不改，不新增隐藏手势。封面失败时使用已有文字封面回退，不新增请求。

### 搜书

去掉橙色大页头，统一纸色页头、搜索框与灰绿主按钮。结果采用纸页分隔的封面/标题/作者/最新章节/书源数量层级，移除粗黑边和橙色侧条。

当前 SearchResultCard 使用文字封面，且现有 UI 没有独立简介数据通道；因此本轮美化文字封面，不新增封面抓取，也不展示演示稿中的虚构简介。真实结果仍逐条出现，已完成书源数、失败折叠详情、重试、空结果和书源准备失败提示全部保留。不得因统一样式移除测试标签或让按钮绕过现有启用条件。

### 书籍详情

纸色页头展示真实封面、书名、作者及当前书源；简介、书源选择、目录依次明确分区。保留「加入书架、开始阅读、整本下载」现有顺序和状态：加入书架使用灰绿主按钮，其余为清晰次按钮；不在外观任务中改变操作优先级或业务回调。

书源选中和当前阅读章节改用灰绿标记，同时保留文字。完整保留目录查找、正倒序、刷新、旧信息保留提示、作品身份不一致警告与待保存状态。长书名、长来源名、简介和多按钮必须可换行或滚动，不遮挡操作。

### 下载

纸面任务卡取代粗黑边框。书名、来源、状态、进度条与操作层级清晰；保留真实章节数、已保存大小、失败章节、当前章节和正在下载时的速度。状态不能仅靠不同颜色表达。

保留新任务网络默认、现有任务网络提示、忙碌禁用、暂停/继续/重试/停止/打开/删除等当前可用操作及所有确认。移动数据规则、WorkManager 调度和后台通知不在本轮改变。

### 书源

纸色页头和一致的导入/测试按钮替换黑橙块。每项保持名称、HTTP/HTTPS、内置/导入、域名、健康状态、开关及测试/删除入口。

HTTP 明文警告、网站验证、导入问题列表和删除自定义书源确认保持可见且措辞含义不变；不能为追求安静外观隐藏风险。内置书源仍不可删除，状态和操作启用条件完全沿用原逻辑。

## 架构与数据边界

1. 新建语义化的纸页主题 tokens/typography/shape 与少量公共页头、纸面组件；只服务已确认的五页和对应导航、非阅读弹窗。
2. 应用入口按「正在阅读 / 非阅读界面」明确隔离主题。现有 NovelRadarTheme、旧全局颜色和阅读子树保留，非阅读分支采用新的 PaperStudyTheme；不要直接改全局 SignalOrange 等常量。实际 ReaderControls 仍引用 SignalOrange，盲目全局替换会越过范围。
3. 五个 Screen 及 SearchResultCard 只调整呈现。现有 UiState、ViewModel、repository、SourceEngine、下载协调、缓存、schema、用户偏好和权限流程不改；不添加数据库迁移。
4. 交互仍由原回调传递；不新增自动搜索、额外网络请求、分页业务状态、书架排序/分组或封面下载任务。共享封面组件如需调整装饰，不改变其获取、缓存与回退行为。
5. 保持 book/source/chapter/task 标识、Lazy key、testTag 和无障碍身份，避免重组导致重复回调或阅读记录变化。页内本地展开状态仍按原规则保存。
6. App 名称、包名、版本、签名、用户图标与已交付 APK 不动；任何新测试包另命名，不覆盖旧产物。

## 错误、空态与安全

保持已有错误解释和恢复操作，统一纸面容器与字号，不将错误替换为「网络异常」等笼统信息。搜索失败仍可展开原因；目录/书籍刷新失败继续保留旧内容；下载失败、计费网络选择、HTTP 风险和删除本地数据确认不能弱化。

禁用必须既有视觉表现又阻止回调；重试与加载使用真实状态，不展示演示稿成功数字。外观改版不承诺加速书源或扩大搜书覆盖范围。
