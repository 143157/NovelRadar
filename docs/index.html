01 / SIGNAL

一本书，不该被埋在十几个站点里。

NovelRadar 用配置驱动的书源规则连接不同站点，把搜索、详情、目录和正文解析拆成同一条可测试的管线。你看到的是一张结果卡，背后是并发、去重与失败隔离。

SEARCH / 01

多源并行，只留一张卡片

同时询问已启用的书源，按书名与作者合并结果。一个来源超时或解析失败，只影响它自己的状态。

LOCAL / 02

书在手机里，不在云上

Room 保存书架与进度，章节正文独立文件原子写入。断网时，已下载的章节仍然能读。

PAPER / 03

把界面调成纸的颜色

日间、纸张、夜间三套主题；字号、行距、页边距都能改。阅读器只做一件事：让正文留在视线里。

这不是视频，也不是截图。点一下搜书、翻到阅读器、暂停一次下载，看看它真正的工作方式。

03 / SPEC

一把安静的工程尺。

没有账号系统，没有推荐流，也没有服务端。所有复杂度都收在书源引擎和本地存储里，剩下的交给阅读。

BUILD NOTES

规格驱动 + TDD。先写设计与实施计划，再按任务补测试、实现、回归和验收。开发过程中使用 Codex AI 编程代理协助代码生成与测试补齐，维护者负责架构决策、验收与发布。

“阅读器只做一件事：让正文留在视线里。”
